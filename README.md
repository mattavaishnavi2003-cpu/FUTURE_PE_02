# FUTURE_PE_02
# AI-Powered UGC Ad Prompt System (Cetaphil) 🧴✨

## 🎯 Project Overview
This project focuses on building a reusable prompt engineering system designed to generate high-converting, authentic User Generated Content (UGC) ad scripts for **Cetaphil Gentle Skin Cleanser**. 

## 🛠️ The Prompt Framework
The system utilizes a structured **Problem ➔ Solution ➔ CTA** framework designed to appeal to consumers struggling with skin sensitivity and breakout-prone skin.

## 📂 Repository Structure
*   `/prompts/system_prompt.txt`: Contains the structured system instructions used to guide the AI.
*   `/outputs/cetaphil_ad_pack.md`: Contains the final generated hooks, full video scripts, and platform-specific captions.

## 🧠 Key Insights & Learnings
*   **Authenticity Over Polish:** UGC succeeds because it mimics a recommendation from a trusted peer rather than an aggressive sales pitch.
*   **Hook Variation:** Building multiple distinct hooks allows marketing teams to A/B test variations to capture low-attention social media scrolls within the first 3 seconds.
